# Bundled typeface

`gelasio-bold.woff2` is Gelasio Bold (weight 700 cut from the variable font `ofl/gelasio/Gelasio[wght].ttf` in google/fonts, reduced to Latin letters, digits and punctuation). It stands in for Georgia Bold where Georgia is not installed, and has the same letter widths. Licensed under the SIL Open Font License 1.1: [OFL-Gelasio.txt](OFL-Gelasio.txt).
